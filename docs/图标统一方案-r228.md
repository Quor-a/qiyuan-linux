## 四、统一建议

1. **icon_btn 助手提升到公共层**（当前 qybrowser.c:30 / qycalc.c:193 / qyfiles.c:42 / qysearch.c:38 四份完全重复）：
   - qyicon.h 增加：
     ```c
     GtkWidget *qy_icon_button(QyIconId id, int px, const char *tip);
     GtkWidget *qy_icon_tab_label(QyIconId id, const char *label); /* 可选，二期 */
     QyIconId    qy_icon_for_app(const char *name);                /* 统一应用名映射 */
     ```
   - qyicon.c 实现，删除 4 个本地 static `icon_btn`，统一改调 `qy_icon_button`。
2. **应用名映射统一**：qydesktop.c:241 `task_icon_id` 与 qyappmenu.c:121 `app_icon_id` 是两份近似映射，建议合并为 `qy_icon_for_app()`。
3. **task_icon_id 覆盖补全**：当前只覆盖 文件/终端/设置/监视/软件中心/回收站/文本/图片/压缩/浏览器；缺 音乐、搜索、截图、剪贴板、网络、锁、安装、用户、驱动、Git、欢迎、切换、计算器。补全映射（多为现有枚举），并新增 `QY_ICON_CALC`（qycalc 目前无图标）。Dock 应用表（qydesktop.c:57）与桌面图标已全部有对应枚举，无需新增应用图标。
4. **编译链**：qydesktop.py 中给 qysettings/qymedia/qyview/qyedit/qyusers 等新增接入 qyicon 的编译行追加 `qyicon.c`。
5. **清理**：删除 qydesktop.c `make_tray_btn` 死代码；qybrowser/qyappmenu 的 5 处 `gtk_button_new_from_icon_name` 清零。
6. **字符归零复查**：改完后 `grep -P '[\x{2190}-\x{2BFF}]' recipes/*.c` 仅允许注释；`qysearch` 的 `•/S`、`qyview` 的 `< >`、`qyedit` 的 `+ -`、`qyusers` 的 `＋` 必须清零。
