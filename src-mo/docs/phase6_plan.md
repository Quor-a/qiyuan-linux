# 阶段六计划：真实程序与发布准备

起点：2026-10-08，阶段一~五完成，54+ 项测试，自举稳定

## 目标

让墨语言能写出**别人愿意读、愿意跑**的程序，
并把项目整理成可以对外发布的形态。

判断标准很具体：再写两个真实程序，不靠 workaround，
且 `README` 能让一个陌生人在 5 分钟内跑起来。

### D. 明确不做（0.1 之前）

- 寄存器分配（需要数据流分析，改动面大）
- 常量折叠（需要中间表示或延迟发射）
- 调试信息 DWARF（信息量大，与优化冲突）
- 包管理（还没有模块系统）
- byte / bool / float 等机器类型

## 硬规则（沿用至今）

1. **改语法必须同时改 seed 的汇编**，否则自举立刻不一致
2. **只影响诊断的改动不必镜像 seed**（如缺少 return 检查）
3. 每步跑 `bash verify_bootstrap.sh`，三级 md5 必须一致
4. 加语言特性就加测试，正常用例 + 错误用例各一

## 风险

| 风险 | 缓解 |
|---|---|
| `break` 在嵌套循环中跳错标签 | 用栈式标签，退出块时弹出 |
| 字符字面量与字符串字面量词法冲突 | 用单引号区分，词法层加分支 |
| tests/ 下库副本不同步 | 改为编译前自动拷贝，或让 import 搜索路径兜底 |
