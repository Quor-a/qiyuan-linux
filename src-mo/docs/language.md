# 墨语言（Mo）语言参考

适用版本：1.0.0

墨语言是一门静态类型、直接生成 ELF64 可执行文件的编译型语言。
编译器用墨语言自己写成，并能编译自身（自举）。

---

## 1. 程序结构

一个程序由若干声明组成，顺序不限：

```mo
import "io.mo";          # 引入其它文件

var counter: i64 = 0;    # 全局变量

struct Point {           # 结构体
    x: i64;
    y: i64;
}

fn add(a: i64, b: i64) -> i64 {    # 函数
    return a + b;
}

fn main() -> i64 {       # 入口
    return add(1, 2);
}
```

- 注释以 `#` 开头，到行尾结束
- 入口是 `fn main() -> i64`，返回值即进程退出码（只取低 8 位）
- 定义顺序无关：可以先调用后定义，跨文件也行

---

## 2. 类型

| 类型 | 说明 |
|---|---|
| `i64` | 64 位整数，唯一的基础数值类型 |
| `byte` | 1 字节无符号；存储时截断，读取时零扩展 |
| `ptr` | 指向字节的指针，用于字符串与缓冲区 |
| `[N] T` | 定长数组，N 必须是正整数常量 |
| 结构体 | `struct` 定义的复合类型 |

没有浮点、没有布尔类型（用 `i64` 的 0/1 表示）。

---

## 3. 变量

```mo
var g: i64 = 0;          # 全局，程序运行期一直存在，初值必须是常量
let x: i64 = 10;         # 局部，在函数内
let a: [8] i64;          # 局部数组（不初始化）
var b: [8] byte = 0;     # 全局 byte 数组
```

赋值与复合赋值：

```mo
x = x + 1;
x += 1;  x -= 1;  x *= 2;  x /= 2;  x %= 3;
x &= 0xf;  x |= 1;  x ^= 1;
```

数组与结构体不能被整体赋值（`a = b` 会报错），只能逐元素。

---

## 4. 函数

```mo
fn fib(n: i64) -> i64 {
    if n < 2 { return n; }
    return fib(n - 1) + fib(n - 2);
}
```

- 参数与返回值目前都按 `i64` 传递；`ptr`、`byte` 也可作参数
- 支持递归和互递归
- 前 6 个参数走寄存器，第 7 个起走栈
- 函数末尾必须出现 `return`（编译器做保守检查：完全没写会报错，
  但某个分支漏写不会报）

---

## 5. 运算符

按优先级从低到高：

| 类别 | 运算符 |
|---|---|
| 逻辑或 | `\|\|` |
| 逻辑与 | `&&` |
| 位或 | `\|` |
| 位异或 | `^` |
| 位与 | `&` |
| 相等 | `==` `!=` |
| 关系 | `<` `>` `<=` `>=` |
| 移位 | `<<` `>>` |
| 加减 | `+` `-` |
| 乘除取余 | `*` `/` `%` |
| 一元 | `-` `!` `&`（取地址） |

- `/` 与 `%` 是带符号除法，向零取整
- `!` 返回 0 或 1
- `&` 作一元是取地址，作二元是按位与，靠语法位置区分

---

## 6. 控制流

```mo
if x > 0 {
    return 1;
} else if x == 0 {
    return 0;
} else {
    return -1;
}

while i < 10 {
    if i == 5 { i += 1; continue; }
    if i == 8 { break; }
    i += 1;
}
```

- `break` / `continue` 只作用于最内层循环，在循环外使用会报错
- 花括号不能省略

---

## 7. 数组、指针与字符串

```mo
let a: [4] i64;
a[0] = 1;
let i: i64 = 2;
a[i] = a[i - 1] + 1;
```

- 下标越界会被拦住并终止程序（退出码 1，打印 `index out of bounds`）
- 编译期常量下标越界直接编译报错
- `ptr` 用于逐字节访问：

```mo
let s: ptr = "hello";
let c: i64 = s[1];       # 101
let n: i64 = strlen(s);  # 5
```

- 字符串字面量可以直接下标：`"hello"[1]`
- 字符串以 0 结尾，字面量存储在只读数据区
- 字符字面量：`'a'`、`'\n'`，值就是字符编码

---

## 8. 结构体

```mo
struct Inner { v: i64; }
struct Outer {
    a: i64;
    in: Inner;
    b: i64;
}

let o: Outer;
o.a = 1;
o.in.v = 2;
let x: i64 = o.in.v;

let arr: [3] Outer;      # 结构体数组
arr[0].a = 5;
```

字段按声明顺序连续布局，嵌套结构体内联展开。

## 9. 内建函数

| 函数 | 说明 |
|---|---|
| `load8(p)` / `load64(p)` | 从地址读 1 / 8 字节 |
| `store8(p, v)` / `store64(p, v)` | 向地址写 1 / 8 字节 |
| `syscall(n, a1..a6)` | 系统调用，返回rax |
| `argc()` | 命令行参数个数 |
| `argv(i)` | 第 i 个命令行参数（0 是程序名） |

标准库提供 `print` / `print_i64` / `strlen` / `streq` / `strcpy` /
`strcmp` / `memset` / `memcpy` / 文件读写 / 简易分配器 / 断言框架。

---

## 10. 模块

```mo
import "io.mo";
import "lib/str.mo";
```

- 所有文件共享同一张符号表，靠回填实现跨文件调用，顺序无关
- 重复 import 同一路径只编译一次，循环 import 合法
- 搜索顺序：相对当前文件 → `lib/<basename>` → `../lib/<basename>`

---

## 11. 编译与运行

```bash
moc prog.mo prog.elf        # 编译
moc prog.mo -g prog.elf     # 带调试信息（gdb 可按源码行下断点）
./prog.elf                  # 运行

bash tools/mobuild.sh main.mo -o app.elf   # 递归解析 import 并构建
bash tools/fmt.mo 的用法见下
```

格式化工具（`tools/fmt.mo` 编译后）：

```bash
fmt file.mo          # 输出到 stdout
fmt -w file.mo       # 就地写回
```

它只调整空白（缩进、行尾空格、末尾换行），不改 token 流。

## 12. 已知限制

| 项 | 说明 |
|---|---|
| 只有整数类型 | 没有浮点、没有真正的布尔 |
| ~~没有动态数组~~ | ✅ 1.1.0 起有 `lib/vec.mo` |
| 没有完整寄存器分配 | 1.0 只做了栈顶缓存；完整版需先有 IR，见 `docs/regalloc_design.md` |
| `ptr` 不带长度 | `p[i]` 不做越界检查 |
| 结构体不能整体赋值或按值传参 | 只能逐字段 |
| 没有 `<<=` `>>=` | 需要三字符 token 支持 |
| 调试信息只有行号 | gdb 能下断点，但不能 `print 变量名` |
| 只支持 x86-64 Linux | 直接产出 ELF64，不接 LLVM |

## 13. 代码生成

编译器边解析边发射代码，没有中间表示（AST/IR）。
1.0 起加入了**栈顶缓存**：二元运算的左操作数放进 `rbx` 而不是压栈，
省掉一对内存访问。`rbx` 在 SysV ABI 里是 callee-saved，
且生成的代码本身不使用它，因此安全。

维持不变式「`rbx` 里是最后一次 push 的值」，任何新的 push 之前
都会先把旧值落栈，所以嵌套表达式与函数调用都正确。

实测收益（相对优化前）：数组密集程序约 -15%，字符串处理约 -33%，
纯函数调用递归无变化。

完整的寄存器分配需要中间表示，属于 1.x 的议题。
