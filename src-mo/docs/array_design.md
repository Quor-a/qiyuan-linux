# 墨语言数组设计

状态：已实现（阶段一 · 第 1 周）
日期：2026-10-08

## 1. 语法

```
var g: [8] i64 = 0;        # 全局数组：8 个元素，全部初始化为常量

fn f() -> i64 {
    let a: [16] i64;       # 局部数组：16 个元素，栈上分配，不初始化
    a[0] = 1;
    a[1] = a[0] + 2;
    g[3] = a[1];
    return a[1] + g[3];
}
```

- 元素类型恒为 `i64`，元素大小固定 8 字节。
- 下标从 0 开始，下标表达式可以是任意 i64 表达式。
- 数组的声明、读写都用 `[` `]`，与 C 一致。

## 2. 内存布局

| 种类 | 位置 | 布局 |
|---|---|---|
| 全局数组 | 数据段（0x10000000 起） | 连续 `8*n` 字节，按声明顺序紧邻分配 |
| 局部数组 | 当前函数栈帧 | 连续 `8*n` 字节，基址偏移为负 |

局部数组偏移推导（栈向下生长）：设分配前 `cur_fn_off = P`，

```
off0   = P - 8*(n-1)        # a[0] 所在偏移
cur_fn_off = P - 8*n        # 分配后
```

例：`P = -8, n = 4` → `off0 = -32`，`cur_fn_off = -40`。
数组占 `[rbp-32, rbp-8]`，`a[i]` 地址 = `rbp + (-32) + i*8`。

标量仍按原规则：`off = P`，然后 `cur_fn_off = P - 8`。

## 3. 代码生成

基址取法：

| 种类 | 指令 |
|---|---|
| 全局 | `movabs rax, addr` （48 B8 imm64） |
| 局部 | `lea rax, [rbp+off0]` （48 8D 85 disp32） |

下标读 `a[i]`：

```
<计算 i>            ; rax = i
shl rax, 3          ; 48 C1 E0 03
push rax
<取基址>            ; rax = base
pop rcx
add rax, rcx        ; 48 01 C8     rax = base + i*8
mov rax, [rax]      ; 48 8B 00
```

下标写 `a[i] = v`：

```
<上述取地址序列，但不做最后的 load>
push rax            ; 保存地址
<计算 v>            ; rax = v
pop rcx
mov [rcx], rax      ; 48 89 01
```

## 4. 语义约定与已知限制

- 数组名不带下标单独出现时，按**标量取值**处理（即 `a` 取 `a[0]` 的值）。
  这是实现简化，后续类型系统阶段会改为编译期报错。
- **不检查下标越界**。越界检查放到阶段二（类型系统与诊断）统一处理。
- 全局数组初始化目前只支持单个常量填充（`= 0`），不支持 `{1,2,3}` 列表。
  列表初始化留到标准库阶段一并处理。
- 不支持二维数组。等结构体落地后用「数组的数组」或结构体承载。

## 5. 符号表影响

**不需要新增数组标志位**。判断依据完全来自语法位置（`name[`），
因此 `sym_add` 的签名与布局不变，改动面最小。

## 6. 回归要求

改动后必须跑 `bash verify_bootstrap.sh`：seed 编译新 compiler.mo 得到 moc1，
moc1 再编译 compiler.mo 得到 moc2，两者 md5 必须相同（不动点）。
注意：compiler.mo 自身**不使用**数组语法，以保证 Stage0 汇编版 seed 仍能引导。

## 8. 后续补充：取地址 `&`（第 3 周前置完成）

数组要传给函数，必须能拿基址。加入一元 `&`：

```
fn sum(p: i64, n: i64) -> i64 {
    let s: i64 = 0;
    let i: i64 = 0;
    while i < n { s = s + load64(p + i * 8); i = i + 1; }
    return s;
}
fn main() -> i64 {
    let a: [5] i64;
    a[0] = 1; a[1] = 2; a[2] = 3; a[3] = 4; a[4] = 5;
    return sum(&a, 5);        # 15
}
```

- `&name` 对局部变量发射 `lea rax, [rbp+off]`，对全局变量发射 `movabs rax, addr`。
- 对数组取 `&a` 得到 `a[0]` 的地址（即前面定义的 `off0`）。
- 指针是整数，算术按**字节**进行，所以遍历要写 `p + i * 8`。
- 一元 `&` 与二元 `&`（按位与）靠语法位置区分，词法层无需改动。

至此「数组 + 取地址 + 指针遍历」闭环可用，数组不再是只能本地使用的孤岛。
